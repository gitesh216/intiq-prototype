# INTIQ Rewards — High-Fidelity Prototype

A desktop-first, demonstration-ready React + TypeScript + Vite prototype for INTIQ Rewards.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL (normally `http://localhost:5173`).

## Demo flow

1. Start on the login screen.
2. Choose **Member** and sign in.
3. Open **Available Schemes** → **Summer Growth Accelerator**.
4. Click **Submit Purchase** → submit the demo invoice.
5. Open the scheme again → **Simulate Validation**.
6. Watch 2,500 IQ move from Pending to Available.
7. Open **Rewards** → redeem a reward.
8. Use the sidebar **Partner View** switch to explore the Partner experience.
9. Partner side: **IQ Points** → Purchase IQ Points, or **Schemes** → Create New Scheme.

Everything is local/mock state. No backend, database, authentication, payments, or external business integrations are required.
